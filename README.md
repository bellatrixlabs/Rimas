# Rimas

Agora que conquistei a habilidade de fazer **Web Scraping**, meu horizonte aumentou drasticamente, então farei um app de rimas completo.

## Bibliotecas ultilizadas 

### Requests 

Nesse projeto a biblioteca **requests** servirá para fazer uma **requisição HTTP** ao site que contém o banco de dados de rimas.

### BeautifulSoup 

BeautifulSoup cuidará de entregar as informações essenciais e necessárias que iremos usar para criar nosso software.
