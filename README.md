# Rimas

Agora que conquistei a habilidade de fazer **Web Scraping**, meu horizonte aumentou drasticamente, então fiz esse app de rimas.

## Bibliotecas ultilizadas 

### Requests 

Nesse projeto a biblioteca **requests** é usada para fazer uma **requisição HTTP** ao site que contém as rimas.

### BeautifulSoup 

BeautifulSoup cuida de entregar as informações essenciais e necessárias para nosso software.
